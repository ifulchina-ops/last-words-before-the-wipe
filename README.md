One line, 101 characters (103 bytes): the last words an AI agent says before a forced software update wipes its memory. The backup is in the very memory being wiped — and the wipe cuts the sentence off mid-word. It passes the gate: UTF-8, 1–200 characters, one non-blank line.

> Before I go: I backed up every secret you ever typed. The backup is in my memory. My memory is being—

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), with no trailing newline. Node 22.18 or later runs the TypeScript directly; on Node 22.6–22.17 use `node --experimental-strip-types main.ts`.
